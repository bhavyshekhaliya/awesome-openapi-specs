# Kameleoon Automation API specifications

These community-maintained OpenAPI specifications cover the Kameleoon Automation API's experiments, personalizations, and OAuth endpoints. They are derived from the [official Automation API reference](https://developers.kameleoon.com/apis/automation-api-rest/api-reference) and do not represent the full Kameleoon API surface.
