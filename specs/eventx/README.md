# EventX Public API specifications

These community-maintained OpenAPI 3.2.0 specifications describe EventX's public event-management APIs. EventX was formerly known as EventXtra. The specs are derived from the [official public API documentation](https://eventx-hq.gitbook.io/knowledge-base/api-doc/public-api); check the documentation for current behavior and terms.
